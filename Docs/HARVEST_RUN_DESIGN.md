# 풍년런 — 잭팟런 테마 · 용어 · 거는 장치 개편 (설계, 2026-11-23)

## 0. 사용자 결정 (2026-11-23)

- 목적: 게임물 등급분류에서 **사행성(도박 흉내)으로 보이지 않게**. 잭팟런은 돈 · 재화를 걸지 않고 점수만 얻지만, 슬롯머신 · 릴 · 잭팟 · 코인이 게임의 중심이라 「사행행위 모사가 주된 내용 → 청소년이용불가」 위험이 있다.
- 범위: **겉모습 · 용어 + 거는 장치만**. 규칙 · 밸런스 엔진(확률표 · EXP/점수 공식 · 요구치 · 상점 경제)은 그대로.
- 테마: **🌱 씨앗 밭** — 밭에 씨앗을 뿌리면 칸마다 무작위 작물이 자라고, 같은 작물이 모이면 수확 점수.
- 이름: **풍년런**. 주소(jackpotrun-web) · 저장 키(localStorage `slotweb_*`) · 랭킹 · 별사탕 연동 · 내부 id 는 그대로.
- 그림: 코덱스로 지금 그림체에 맞춰 새로(§6, 메인 세션 담당).

## 1. 바꾸지 않는 것 (모든 갈래 공통)

- 내부 id · 함수 이름 · 변수 · 상수 이름 · 상태 필드 · localStorage 키 · `data-act` 값 · CSS 클래스 이름 · 그림 파일 이름(id) — **화면에 보이는 글자와 이모지만** 바꾼다(예: 심볼 id `coin` 그대로, 보이는 이름만 「도토리」).
- 확률 · 가중치 · 수치(아래 §3 의 두 장치 제외) · 심화 모드 규칙 · 승천 · 랭킹 분리 · fmt2 표기(소수 2자리 · 끝 0 제거).
- 코드 주석은 고치지 않아도 된다(필요한 곳만). 사용자에게 보이는 글자가 기준.

## 3. 거는 장치 (규칙 변경 — 일반 모드)

### 3.1 올인 → 💧 듬뿍 물주기 (`mode "ALLIN"` 그대로)
- 지금: 코인 4(누진 · 보스 +1)를 내고 EXP ×2.5, **해골이 1개라도 나오면 0** — 걸고 잃는 구조.
- 바꿈: 비용은 그대로, **EXP ×1.5 항상**(실패 없음). `C.ALLIN_MUL = 1.5`, `C.ALLIN_FAIL_SKULLS` 는 더 쓰지 않는다(상수는 남겨도 되나 효과 없음 — 지우면 하네스 · 참조도 같이).
  - 기댓값 근거: 해골 가중 10/100, 5칸 모두 해골 없음 = 0.9^5 ≈ 0.59 → 예전 기댓값 ≈ ×1.48. 새 값 ×1.5 는 기댓값이 같고 흔들림만 없앤 것. → **§7.1 에서 ×1.2 로 낮춤**(흔들림이 사라진 만큼 런이 강해져서).
- `applySpecialSpin` ALLIN: `{ exp: exp * C.ALLIN_MUL, note: "💧 듬뿍 물주기 ×1.5" }`(fmtMul 사용). `cmdEffectDesc` ALLIN: `EXP ×1.5 (실패 없음)`.
- 올인과 이어진 문구(보스 counter 「🎲올인」, 증강 · 캐릭터 설명의 「올인」)는 「듬뿍 물주기」 또는 문맥에 맞는 말로.

### 3.2 앵콜 → 🧺 덤 수확 (`encoreSpin` · `encoreCashOut` 등 이름 그대로)
- 지금: 클리어 점수(판돈)를 걸고 성공마다 배율이 오르는 팟, **BUST 면 판돈까지 소멸** — 더블업 구조.
- 바꿈(잃는 것 없음):
  - 조건은 같다: 일반 모드 · STAGE_CLEAR · 남은 심기 ≥ 1 · `encoreStake`(= 이번 클리어 점수) > 0. **`r.score >= stake` 조건과 점수 차감은 없앤다.**
  - 덤 수확 한 번 = 남은 심기 1개를 쓰는 일반 굴림(지금처럼 그 굴림의 EXP · 점수는 버리고 도토리 수입만).
  - 성공(지금 BUST 조건의 반대 — 페어 이상 AND 해골 `ENCORE_BUST_SKULLS` 개 미만) → **덤 = floor(stake × C.ENCORE_STEP)** 을 그 자리에서 `r.score` 에 더한다. `C.ENCORE_STEP`(성공마다 같은 크기 — 쌓아 올리는 배율 없음, **§7.1 에서 0.1**).
  - 실패 → 아무것도 잃지 않는다(덤 0). 덤 수확은 끝나지 않고 남은 심기가 있으면 또 할 수 있다.
  - 「정산」 개념이 없다: 받은 덤은 이미 점수에 들어가 있다. `encoreCashOut` · `proceedToNodes` 는 그냥 다음으로 넘어간다(`_encoreSettle` 은 더할 팟이 없으니 상태만 정리).
  - 상태 필드는 이름을 유지하되 뜻을 바꾼다: `encoreK` = 성공 횟수, `encorePot` = 이번 클리어에서 받은 덤 합계(표시용), `encoreActive` = 한 번이라도 덤 수확을 했는지, `encoreLastBust` = 직전 덤 수확이 실패였는지(화면 문구용), `encoreDone` = 남은 심기가 없거나 노드로 넘어감.
  - `state().encore` 의 키 순서 · 이름은 그대로(`available, active, k, pot, stake, lastBust, nextMul`). `nextMul` 은 이제 「다음 성공 때 받을 덤 비율」= `C.ENCORE_STEP`(0.25) 고정.
  - 토스트 · 소리: 성공 「🧺 덤 수확 +N점」(sfx `encoreup`), 실패 「🌾 이번엔 덤이 없었어요 — 잃은 건 없어요」(sfx 는 `bust` 대신 부드러운 소리 — 화면 갈래가 sound.js 에 `nobonus` 를 만든다. game.js 는 그 이름을 부른다).
  - 남은 심기 점수(`C.SCORE_PER_LEFTSPIN`)는 지금처럼 클리어 때 이미 계산된다 — 덤 수확은 그 뒤의 선택이라 그대로 둔다(덤 수확에 쓴 심기는 노드 이후에 남지 않는다 — 지금과 같은 소모 규칙).
- 업적 · 카운터가 앵콜 성공/BUST 를 세고 있으면 그대로 동작하게(BUST 카운터는 실패 횟수로 계속 세도 된다).

### 3.3 니어미스 · 기대감 연출 (화면 갈래)
- 니어미스(결과가 아닌 심볼이 「아깝게 스쳐 가는」 연출)는 도박 기계의 심리 장치라 **없앤다**(코드 · `nearmiss` 소리 · `.nm-*` 클래스 사용 중지).
- 마지막 칸 기대감(유지 구간 연장 · 줌 · 골드 펄스 · `antic` 소리)도 **없앤다**. 마지막 칸도 다른 칸과 같은 간격으로 자란다.

### 3.4 그대로 두는 확률 요소 (보고만)
- 「기도(PRAY)」(도토리 3 → 8% 확률 ×3 · 뒤처지면 +25)와 증강 · 아이템의 확률 효과는 가진 것을 걸지 않으므로 이번에는 그대로 둔다. 이름에 도박 말이 있으면 §4 대로 바꾼다.

## 5. 화면 · 소리 (ui.js · style.css · index.html · sound.js · public/ranking)

- **제목**: `<title>🌾 풍년런</title>`, theme-color `#0d1a12`. 첫 화면 · 결과 · 공유 · 랭킹 화면의 게임 이름 → 풍년런.
- **색**: 네온 카지노 → 밤 들판. `:root` 바탕 · 패널 · 테두리 토큰만 바꾼다: `--bg0:#08110c; --bg1:#0e1a13; --bg2:#13241a; --panel:#152219; --panel2:#1b2c20; --panel3:#24392a; --bd:#2c4634; --bd2:#41644b;` 강조색(--gold 등)은 그대로. 파일 머리 주석의 「네온 아케이드」 문구도 정리.
- **밭 칸(.reel)**: 흙 칸 모양 — 배경 `linear-gradient(180deg,#6b4527,#45291a)`, 테두리 풀색 `#5f8f3e`(2px), 안쪽 그림자. 심볼 그림은 그 위에 그대로.
- **심기 연출(릴 회전 대체)**: `spinReelOne` 의 세로 스트립 스크롤을 없애고, 칸마다 `R_STAGGER` 간격으로 ① `.sowing`(흙 칸이 0.25초 들썩 — scale/rotate 작은 흔들림) ② 가운데 칸을 결과(landCell)로 바꾸고 ③ `.sprout`(0.32초 — scale .2→1.12→1 + 아래에서 위로 10px) ④ 소리 `sprout`. DOM 구조(`.rstrip` · 가운데 칸 · 지키기 표시 · `reelTap`)와 결과 결정 방식(결과가 먼저 정해지고 연출은 착지만)은 그대로 둔다. 지키기 칸은 지금처럼 그대로 두는 연출.
- **니어미스 · 기대감 없애기**(§3.3). 인트로의 릴 회전(introTimer)은 작물이 하나씩 피어나는 연출로 바꾸거나 멈춘 화면으로.
- **큰 수확 연출**: 5칸(대풍작) · 빅윈 단계의 분홍 네온 흔들림 · 반짝이를 황금빛 · 풀빛 빛남과 떨어지는 잎(🍃 — 기존 confetti 코드에 잎 색 · 모양)으로. 큰 글자 「JACKPOT」 · 「NICE/BIG/MEGA」 → 「대풍작!」 · 「좋은 수확!」 · 「풍성한 수확!」 · 「엄청난 수확!」.
- **덤 수확 화면**(§3.2): 「판돈 · 팟 · 정산 · BUST」 말을 없애고 「남은 심기로 덤 수확 — 성공하면 이번 클리어 점수의 25% 덤, 실패해도 잃는 건 없어요」 · 받은 덤 합계 · [🧺 덤 수확] [다음으로]. 「정산」 단추는 「다음으로」.
- **듬뿍 물주기**: 특수 심기 단추 · 설명 · 확인 문구 · 결과 문구.
- **소리(sound.js)**: `spin` → 흙 사각 소리(짧은 noise, 필터 600Hz, 음량 낮게 — 톱니파 상승음 없앰) · `reel` 은 `sprout` 와 같은 소리(사인 520→780Hz 짧게, 「퐁」) · 새 `sprout` · `coin` → 나무 「톡」(triangle 700Hz 0.06초) · 새 `nobonus`(부드러운 하강 두 음, triangle 440→330, 작게) · `nearmiss` · `antic` · `bust` 는 부르는 곳을 없앤다(정의는 남겨도 됨).
- **public/ranking**: 보이는 게임 이름만 풍년런(구조 그대로).
- 모바일 360px 에서 가로 넘침 없게. `--sc` 축 규칙 유지.

## 7.1 밸런스 결정 (1차 검수 뒤 — 2026-11-23)

1차 구현(×1.5 · 25%)을 검수 시뮬(일반 모드 400런 · 첫 캐릭터 · 첫 밭 · 상점 안 씀)으로 재 보니, 흔들림을 없앤 만큼 런 단위로 강해졌다. 랭킹이 이어지므로 **옛판 평균 점수에 맞췄다**.
